# Himalayan Trails Nepal - Premium Trekking Website

A modern, cinematic, and fully responsive trekking website for Nepal featuring stunning visuals and smooth animations.

## 🏔️ Features

### Design
- **Modern Cinematic Aesthetic**: Premium adventure-tourism vibe with glassmorphism effects
- **Fully Responsive**: Works seamlessly on desktop and mobile devices
- **Smooth Animations**: Powered by Framer Motion for immersive interactions
- **Dark Mode**: Beautiful dark theme inspired by Himalayan nights
- **Accessibility**: Built with semantic HTML and ARIA labels

### Sections
1. **Hero Section** - Full-screen banner with animated mountains and CTAs
2. **Trekking Packages** - 6 curated trek packages with ratings and pricing
3. **Why Choose Us** - 6 feature cards highlighting our expertise
4. **Interactive Map** - SVG map with clickable trek destinations
5. **Gallery** - Masonry-style image gallery with hover effects
6. **Testimonials** - Animated cards from satisfied travelers
7. **Statistics** - Animated counters showing company achievements
8. **Blog Section** - Latest travel guides and trekking tips
9. **Contact Form** - Glassmorphic booking inquiry form
10. **Footer** - Comprehensive footer with links and social media

## 🚀 Tech Stack

- **Framework**: React 18.2
- **Styling**: Tailwind CSS 3.3
- **Animations**: Framer Motion 10.16
- **Build Tool**: Vite 4.4
- **Icons**: React Icons 4.11
- **Development**: PostCSS, Autoprefixer

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/prapanna2468/himalayan-trails-nepal.git
cd himalayan-trails-nepal

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
